# Page topology

1. Header: supplied logo, anchor navigation, primary upload CTA; mobile menu.
2. Hero: centered oversized headline, short subtitle, two anchor CTAs.
3. Product showcase: gradient panel with conceptual recording/deck artwork.
4. Capability strip: delivery, slides and focused practice; deck marked planned.
5. Upload workspace: recording checker and PDF deck uploader side by side.
   Existing recording request and real Gemma results remain available here.
6. How it works: three concise steps, deck availability explained truthfully.
7. FAQ: native disclosure controls for formats, analysis and local processing.
8. Footer: brand, local processing note and link back to upload.

Natural document scrolling, no scroll-driven tabs or source animation claims.
Anchors have a scroll offset. Desktop upload cards use two columns; mobile
cards stack. Results span the recording card's available width.
