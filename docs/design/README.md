# Design notes

Notes and component specifications written while the landing page was redesigned during the hackathon. `PAGE_TOPOLOGY.md` lists the page sections, `DESIGN_TOKENS.md` and `BEHAVIORS.md` the visual system and interactions, and `components/` one spec per landing-page component. `inspiration.webp` is the visual reference the redesign started from.

These are working notes from 10–11 October 2026; where they disagree with the code in `apps/web`, the code wins.
