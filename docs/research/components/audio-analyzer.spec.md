# AudioAnalyzer

Targets: `src/components/audio-analyzer.tsx`, `analysis-results.tsx`, `pitch-workspace.css`.
The existing recording API and Gemma scoring pipeline are preserved.

Mint card: SVG category icon, step 01, "Make yourself heard." heading, feature
list, illustrated UploadDropzone and full-width analyze button. Native media
preview appears after selection. Reject non-media/empty files, retain valid
selection on invalid replacement, and revoke blob URLs on replacement/removal.

Analyze uses `/api/analyze` and the existing NDJSON stream. Replacement/removal
are blocked during analysis; rapid duplicate submission is guarded. Prepare /
Listen / Score indicators follow real stages. Accessible errors restore controls.

Results span both upload columns; the initial waiting state has no example scores.
Completed analysis focuses the results heading. Overview contains a real Gemma
score in a decorative SVG ring, per-criterion scores/reasons, insights and
improvement suggestions. A sky deck card is explicitly coming soon, with no score.
Pitch moments and audio measurements are separate keyboard-accessible tabs.
Timestamps seek and play the selected recording. Model details use a disclosure.
Missing scores preserve any returned insights and feedback; no scores or feedback
are generated by the frontend. Validation controls display only.

Responsive breakpoints: 960px, 640px, 360px. Reduced motion is respected for
navigation and decorative transitions. Native media controls remain available.
